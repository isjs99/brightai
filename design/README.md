# Brightform Ops UI mockup

Design source for the Brightform Ops mockup (spec v3.0, autonomous account operations).

One artboard per `.dc.html`, laid out by `canvas.json`:

- `Portfolio.dc.html` – accounts landing, this morning's runs
- `Main.dc.html` – the account view (GreatVita): waiting on you, what it found, what changed, what ran
- `Setup.dc.html` – Setup screen on the Autonomy tab
- `CampaignPanel.dc.html` – assisted panel for platform campaign registration (no API)
- `ReplyPanel.dc.html` – escalated CS reply with library retrieval and draft
- `FeedAlternate.dc.html` – low-fi alternate layout for the account view

All figures, account names other than GreatVita, and people are sample data.
