# Brightform Ops Console (clickable mockup)

Single-file web mockup of the Brightform Ops product (spec v3.0). Open `index.html` in a browser.

- Hash-routed: Accounts, Alerts, Bulk actions, Analytics, and per-account Today / Checks / Setup.
- Settings are live state. Ad caps, ROAS floors, product ranges, sample quotas per country,
  pricing rules and promo settings change what the daily run does on the Today tab and in the
  bulk-action previews.
- Sign off and share: Slack summary, client draft, read-only run link.
- All figures are sample data. Every account other than GreatVita and Bears with Benefits is fictional.
